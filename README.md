# CV Fit Score

A Django web app that compares a CV with a job description and returns an AI-generated fit report. CV text is extracted for analysis and is not saved to the database.

## Requirements

- Python 3.10 or newer
- [Ollama](https://ollama.com/) with the `qwen3:8b` model available

## Run locally (Windows PowerShell)

From the project root, create and activate a virtual environment, then install the dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Download the configured model if it is not already installed, and make sure Ollama is running:

```powershell
ollama pull qwen3:8b
```

Start Django:

```powershell
python manage.py runserver
```

Open <http://127.0.0.1:8000/> in your browser. The Django development server is for local development, not production.

## Configuration

The following environment variables are optional; these are the defaults in `cv_analyzer/settings.py`:

| Variable | Default | Purpose |
| --- | --- | --- |
| `QWEN_BASE_URL` | `http://127.0.0.1:11434` | Ollama API base URL |
| `QWEN_MODEL` | `qwen3:8b` | Ollama model used for analysis |
| `QWEN_TIMEOUT` | `120` | Ollama request timeout in seconds |
| `DJANGO_DEBUG` | `1` | Enables Django debug mode when set to `1` |
| `DJANGO_SECRET_KEY` | Local development placeholder | Django secret key; set a private value outside local development |

## CV analysis

Provide a job description and a CV file in PDF, DOCX, or TXT format. CVs must be no larger than 5 MB. The analyzer returns a weighted overall score, component scores, matching and missing skills, strengths, weaknesses, suggestions, and a summary. Scoring is generated by the configured Qwen model and is intended as decision support, not as a measure of a person's worth.

The API endpoint is `POST /api/analyze-cv/`. Send multipart form data with `job_description` and `cv_file` fields. Example using `curl`:

```powershell
curl.exe -X POST http://127.0.0.1:8000/api/analyze-cv/ `
  -F "job_description=Looking for a Python developer with Django experience" `
  -F "cv_file=@C:\path\to\cv.pdf"
```

The API responds with JSON. If Ollama is unavailable, start Ollama and check that the configured model is installed.
